### 결정 M · N 설명 (2026-11-17, 확정: 둘 다 ②, #41)

M과 N은 **모르는 사람의 글과 방이 마을에 보이는가**에 대한 같은 문제의 두 면이다. M은 공유방, N은 광장 대화다. 둘 다 서버가 없는 지금은 급하지 않고, 서버와 공개 가입을 열기 전에 정하면 된다.

#### M. "마을에 공개" 방을 베타에 둘지

| 항목 | 내용 |
|---|---|
| 무슨 문제인가 | 방을 만들 때 공개 범위를 **초대 링크로만**(기본) / **마을에 공개**로 고른다. "마을에 공개"를 고르면 링크를 모르는 사람의 마을 게시판에도 그 모닥불이 보이고 누구나 들어올 수 있다. 지금 코드·SPEC·기능 정의서·DATA_API(`visibility=PUBLIC`)는 이 선택지를 이미 만들어 두었다. 그런데 이 결정 기록은 아직 "열림"이라 문서끼리 어긋난다 |
| 왜 고민하나 | 공개 방은 모르는 사람이 모이는 곳이라 스팸, 욕설, 스포일러, 광고 같은 일이 생길 수 있다. 막으려면 신고, 방 닫기 권한, 개설자 책임 범위, 운영자 개입 기준이 필요하다. 베타는 **초대받은 친구만** 쓰므로 이런 장치 없이도 괜찮다 |
| 선택지 ① | 베타부터 공개 방을 허용하고 신고 기능을 같이 만든다. 공개 방은 개설자가 책임진다. 장점: 새 사람이 들어올 길이 열린다. 단점: 신고 처리 기능과 운영 부담이 베타 전에 생긴다 |
| 선택지 ② (추천) | 베타에서는 **공개 없이 초대만**. 개설 창에서 "마을에 공개" 선택지를 숨기고 서버도 `INVITE`만 받는다. 공개는 공개 가입(출시 2단계) 전에 신고·관리와 함께 연다 |
| ②를 고르면 바뀌는 것 | 개설 창의 공개 범위 항목 숨김, 게시판은 "내가 참여한 방"만 표시, DATA_API의 `GET /rooms`에서 `PUBLIC` 노출 제거(컬럼은 남겨 둠), SPEC·기능 정의서·설명서의 "마을에 공개" 문구에 "공개 가입 이후" 표시. 코드는 선택지 한 줄을 숨기면 된다 |
| ①을 고르면 필요한 것 | 방 신고 버튼과 접수 화면, 신고 누적 시 방 숨김 기준, 개설자 차단·방 강제 종료 권한, 공개 방 목록 정렬과 개수 제한 |
| 정하는 때 | 서버 개설 API(`POST /rooms`)를 만들기 전. 늦어지면 `PUBLIC` 값이 이미 쓰이기 시작해 되돌리기 어렵다 |

#### N. 광장 신고·차단·금칙어를 언제 넣을지

| 항목 | 내용 |
|---|---|
| 무슨 문제인가 | 광장은 책과 상관없이 **마을에 온 모두**가 한 줄씩 말하는 공개 대화다(#34). 공유방과 달리 초대 링크로 거른 사람들이 아니라 그 시간 광장에 있는 사람 모두와 말한다. 그래서 욕설, 도배, 광고, 개인정보 노출이 생기면 막을 수단이 필요하다 |
| 필요한 장치 | **신고**(글을 눌러 신고), **차단**(그 사람 말풍선과 로그를 내게서 숨김), **금칙어 필터**(욕설·광고 단어를 서버에서 가림), 도배 제한(이미 5초에 1건 제한을 설계했다, DATA_API) |
| 아직 정하지 못한 세부 | 글 작성자 표기(닉네임/핸들/익명), 차단 대상 단위, 신고 시 증거 보존. **광장 글은 24시간 뒤 삭제하는데 신고 접수에는 증거가 필요해서 서로 부딪힌다.** 신고된 글만 일정 기간 따로 보관하는 안이 있다 |
| 선택지 ① | 광장을 여는 첫 날부터 신고·차단·금칙어를 모두 넣는다. 장점: 안전. 단점: 베타 친구 수십 명에게는 과하고, 만드는 시간이 길어져 서버 단계가 늦어진다 |
| 선택지 ② (추천) | 베타는 신고 없이 시작하고 **공개 가입(출시 2단계) 전에** 넣는다. 베타 사용자는 초대받은 친구뿐이라 서로 아는 사람이다. 대신 최소 안전장치 두 가지는 처음부터 넣는다: 도배 제한(5초 1건)과 글자 수 제한(40자, 이미 있음) |
| 정하는 때 | 공개 가입을 열기 전 (그 전까지는 광장이 친구끼리의 공간이다). 단 서버를 설계할 때 `plaza_message`에 작성자와 신고 증거 보존 방식을 넣을 자리는 미리 열어 둔다 |

**M과 N의 관계**: 둘 다 ②(베타는 친구끼리, 공개 가입 전에 장치를 넣는다)를 고르면 규칙이 하나로 정리된다: *베타에서는 마을에 모르는 사람이 없다. 모르는 사람이 들어오는 때(공개 가입)에 공개 방 허용, 신고, 차단, 금칙어를 한꺼번에 연다.* 이 경우 M과 N은 "공개 가입 전 필수 작업" 목록 하나로 묶어 관리하면 된다.
