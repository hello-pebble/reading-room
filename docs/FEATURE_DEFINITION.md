## 1. 범위

| 구분 | 내용 |
|---|---|
| 포함 | 내 방 화면, 가구 6개(소파·스탠드·책장·달력·거울·창문) + 문, 마을 화면(광장 대화, 마을 게시판, 공유방 모닥불, 미니맵, 접속 표시), 공유방 개설·대화·가져오기, 월 목표 이력, 캐릭터(유령), 헤더, 신규 알림 표시, 첫 방문 안내 |
| 제외 | 구글 로그인(카카오는 나중에), 서버에서 실제로 친구가 들어오는 초대 처리(프로토타입은 이 브라우저 안에서 흉내), 백엔드 구현, 네이티브 앱 기능(라이브 액티비티, 로컬 알림, 위젯) |
| 데이터 | 프로토타입은 브라우저 `localStorage`(`myroom-proto-v1`)에 저장. 서버 연동 없음 |

## 3. 기능 정의

### 3.1 방과 화면

| ID | 동작 | 규칙·예외 |
|---|---|---|
| RM-01 | 3D 원목 방을 고정된 아이소메트릭 카메라로 보여준다. 바닥은 마룻바닥, 벽은 판벽, 책장·문·창틀은 짙은 호두색. 그림 스타일은 툰 셰이딩(빛 3단 음영 + 얇고 연한 갈색 외곽선, #37)이고 마을·유령도 같다. 폰 폭(760px 이하)에서는 바깥 여백 없이 화면 전체를 채운다 | 방 크기와 카메라는 사용 중 바뀌지 않는다. 확대 연출, 방을 줄이는 사이드 패널은 쓰지 않는다 (#4, #5) |
| RM-02 | 화면 폭 760px 이하는 7×6.5칸 방, 그보다 넓으면 10×8칸 방 | 창 크기가 기준선을 넘으면 방을 다시 그리고 캐릭터는 시작 위치로 돌아간다. 가구 종류와 배치 순서는 같다 (#22) |
| RM-03 | 가구를 누르면 해당 패널이 열린다. 마우스 기기는 호버 시 밝아지고 이름과 상태가 담긴 이름표가 뜬다. 터치 기기는 입장 시 가구가 차례로 잠깐 반짝인다 | 이름표: 소파 · 읽을 책 올리기 / 『제목』 읽는 중, 스탠드 · 꺼짐 / 켜짐 mm:ss / 확인 필요, 책장 · n권, 달력 · 이번 달 완독 a/b권, 전신거울 · 새 아이템 / 꾸미기, 창문, 문 · 마을로 나가기. 키보드 Tab 순서는 소파 → 스탠드 → 책장 → 달력 → 거울 → 창문 → 문. 히트박스는 보이는 가구보다 크다. 퀵바는 없다 (#3) |
| RM-04 | 바닥을 누르면 캐릭터가 그 자리로 걸어간다 | 벽·가구 쪽 가장자리는 이동 범위를 제한한다. 소파 영역을 누르면 소파를 누른 것으로 본다. 앉아 있을 때 바닥을 누르면 일어나서 걸어간다 |
| RM-05 | 입력 화면은 화면 가운데 모달로 뜬다. 제목과 ✕는 위, 액션 버튼은 아래에 고정하고 가운데만 스크롤한다 | 닫기: ✕, 바깥 클릭, ESC. 버튼 문구는 짧게, 아이콘으로 충분하면 아이콘만 (#6, #14) |
| RM-06 | 신규 알림이 있는 가구에 노란 별(✦)이 깜빡인다 | 별이 뜨는 곳은 거울(새 아이템), 창문(가져오기 대기 중인 종료된 공유방), 소파(올려 둔 책이 없을 때. 책을 올리면 사라짐). 가구는 움직이지 않고, 빨간 점·숫자·문 앞 빛은 쓰지 않는다. 해당 가구를 열면 별이 사라진다 (#24) |
| RM-07 | 첫 방문 안내 2단계. 1단계: 소파만 밝게 "소파를 눌러 지금 읽는 책을 올려보세요" [건너뛰기]. 2단계: 책을 올린 뒤 스탠드 강조 "스탠드를 켜면 읽는 시간이 기록돼요" [확인] | 프로토타입에서는 평소에 뜨지 않고 [데모 초기화]를 눌렀을 때만 시작된다. 안내 중에는 다른 가구가 어둡고, 다른 가구를 누르면 "먼저 소파에 읽을 책을 올려보세요"가 뜬다 |
| RM-08 | 헤더에 아바타 얼굴, "○○의 방", `@핸들 · 읽은 책 n권 · (n일 연속 기록) · 오늘 n분 · (⏱ 경과 시간)`을 보여준다 | 연속 기록은 0일이면 숨긴다(방 카드와 달력도 같은 값). "오늘 n분"은 달력과 같은 기준(한국 시간)으로 종료일이 오늘인 세션 전체를 센다. ⏱은 스탠드가 켜져 있을 때만 |
| RM-09 | [데모 초기화]는 저장된 상태를 지우고 처음 상태로 되돌린 뒤 첫 방문 안내를 시작한다 | 프로토타입 전용. 제품에는 없다. **기록이 모두 지워지므로 한 번 누르면 "한 번 더 누르면 모두 지워요"로 바뀌고, 4초 안에 다시 눌러야 실행된다**(안 누르면 원래대로 돌아간다) |

| VL-14 | **갈림길**: 내 집에서 나오면 집 앞길이 갈라진다. 남쪽(화면 왼쪽 아래)으로 내려가면 광장, 동쪽(화면 오른쪽 아래)으로 꺾으면 광장을 거치지 않고 위쪽 길로 모닥불 구역 입구에 닿는다. 갈림길에 푯말이 있고(돌색 판 `광장`, 주황 판 `공유방 모닥불`) 이름표가 떠 있다. 미니맵에도 길이 그려진다 | 광장에서 모닥불 구역으로 가는 길(광장 동쪽 → 구역 입구)도 그대로 있다. 길은 모양일 뿐 걷는 데 제한이 없다. 광장은 집 남쪽으로 옮겼고 이웃·분수대·게시판·연못도 함께 옮겼다. 모닥불 구역 입구 문은 위쪽 길이 닿는 북서쪽으로 옮겼고 광장에서 오는 길은 구역 서쪽의 세로 길로 이어진다. 광장 가운데는 나무 단상 대신 돌 수조·두 단 물받이·물줄기가 있는 분수대다 (#45) |

### 3.11 공유방 대화 (프로토타입 구현됨, 2026-11-17)

모닥불 안에서 하는 대화 화면이다. 마을 광장 대화(VL-10, 한 줄·하루)와 달리 **책 이야기**를 길게 하고 **스포 안내**와 **7일 보관**이 있다 (#18, #33, #34, #38, #43). 기존 모닥불 창(VL-06, VL-09의 방 정보)은 이 화면의 [방 정보] 탭이 된다.

| ID | 동작 | 규칙·예외 |
|---|---|---|
| RC-01 | 열린 방은 마을 게시판·모닥불·창문의 [들어가기](또는 [마을로 가기]로 간 뒤 모닥불)를 누르면 대화 화면이 열린다. 예정 방은 "○○월 ○○일에 열려요"만 보이고 [알림 받기]가 있다. 종료된 방은 읽기 전용(RC-13)이다 | 참여자가 아니면 먼저 초대 링크로 입장한다(베타는 공개 방이 없다, #41). 정원이 찬 방은 "정원이 가득 찼어요"(#32). 사라진 방은 "이 공유방은 사라졌어요" |

| RC-03 | 방에 처음 들어갈 때 한 번 보관 동의 고지를 띄운다: "이 방의 글은 종료 후 7일 뒤 사라져요. 내 서재로 가져가면 다른 사람 이름은 '참여자 A'로 바뀌어요." [동의하고 들어가기] [취소] | 동의 전에는 대화가 보이지 않는다. 개설자도 처음 열 때 한 번 본다. 동의 시각을 저장한다(서버: `room_participant.agreed_at`). 취소하면 참여자가 되지 않는다 |
| RC-04 | 입력줄에 글을 적고 [보내기] 또는 Enter로 보낸다(마우스 기기). 최대 300자, 여러 줄은 Shift+Enter. **폰(터치 기기)은 Enter가 줄바꿈이고 [보내기]로만 보낸다** | 빈 글은 보낼 수 없다. 한글 조합 중 Enter는 보내지 않는다. 도배 방지: 3초에 3건까지("조금 뒤에 보내 주세요"), 직전 글과 같은 글은 30초 안에 못 보낸다("같은 말을 연달아 보낼 수 없어요", #61). 광장 채팅도 같은 규칙이다. 종료·예정 방과 나간 방에서는 입력줄이 없다. 서버: `POST /rooms/{id}/messages` |
| RC-05 | **같은 책 방**: 입력줄 위에 내 현재 쪽이 `📖 124쪽` 칩으로 자동으로 붙는다. 칩을 눌러 쪽수를 고치거나 지울 수 있다. **각자 읽기 방**: 칩이 없다 | 소파에 올린 책이 방의 책이 아니거나 쪽수를 안 적었으면 칩 대신 "소파에서 쪽수를 적으면 글에 붙어요"를 알린다(글은 쪽수 없이 보낼 수 있다). 쪽수는 1~전체 쪽수(상한 9999, #36) |
| RC-06 | **스포 안내**(같은 책 방이고 내가 완독·포기하지 않은 책): 입장 전 확인 카드에 `📖 아직 읽지 않은 책이에요. 대화에 줄거리나 결말이 나올 수 있어요`를 보이고, 들어가면 대화 위에 `📖 안 읽은 책 · 스포 주의` 띠와 [나중에 읽을 책에 담기]를 둔다. 담으면 `담았어요 ✓`로 바뀐다 | 대화는 항상 전부 보인다(쪽수 잠금은 #43으로 폐지). 각자 읽기 방과 완독·포기한 책은 안내가 없다. 지금 소파에서 읽는 책이면 담지 않고 "이미 소파에서 읽고 있어요"를 알린다. 이미 나중에 읽을 책에 있으면 `담았어요 ✓`만 보인다 |

| RC-19 | **모닥불 장면 말풍선**: 모닥불에 앉아 있는 동안 글을 보내거나 받으면 그 사람(나 또는 참여자)의 머리 위(이름표 바로 위, 화면 크기와 상관없이 같은 간격)에 말풍선이 5초간 뜬다. 글이 40자를 넘으면 잘라 `…`을 붙인다. 광장의 말풍선(#34)과 같은 모양을 쓴다 | 모닥불 장면(3D)에서만 나온다. 장면 카메라는 말풍선 여백을 위해 조금 내려 잡는다. 자동 테스트는 3D를 올리지 않아 이 동작은 못 본다. 장면 배경에는 책 제목을 두지 않는다 |
| RC-20 | **모닥불 장면 나가기 확인**: 모닥불 장면에서 ✕, [← 마을로], Esc를 누르면 바로 나가지 않고 `모닥불에서 나갈까요?`를 묻는다. [계속 있기]는 대화로 돌아가고, [마을로 나가기]는 마을로 돌아간다 | 방을 나가는 것(RC-12)이 아니라 장면에서 마을로 돌아가는 것이다. 대화창을 접어 둔 상태에서 눌러도 창을 펼쳐서 묻는다. 마을·내 방의 모달은 ✕로 바로 닫힌다 |
| RC-21 | **모닥불 장면의 대화창은 대화만 둔다**: 대화창 가까이에 동그란 아이콘 버튼 두 개가 있고(PC는 대화창 왼쪽 위에 세로로, 폰은 대화창 위 오른쪽에 가로로, 대화창을 접으면 오른쪽 가장자리로 옮겨 간다), 사람 여러 명 모양이 참여자, `i` 모양이 방 정보다. 아이콘은 직접 그린 SVG이고 글자 없이 설명 말풍선(`참여자`, `방 정보`)만 둔다. 누르면 대화창과 **별도의 모달**이 뜨고 대화창은 그대로 둔다. 모달의 ✕·Esc·바깥 누르기·같은 버튼은 그 모달만 닫고, 모닥불을 나가는 확인(RC-20)은 대화창의 ✕·`← 마을로`·Esc(모달이 없을 때)에서만 뜬다(무심코 ✕를 눌러 나가는 일을 막는다). 대화창 제목은 `대화`이고 탭은 없다. 선택한 버튼은 흰 테두리로 강조한다. 방 정보는 참여자 창과 같은 결로 상자 없이 이름-값 목록(종류·기간·공개 범위)으로 보이고, 초대 링크는 링크 칸 옆의 복사 아이콘 버튼(겹친 사각형, 직접 그린 SVG)으로 복사한다. 참여자는 닉네임을 바둑판(폭에 따라 3열 안팎)으로 배열하되 테두리 상자 없이 글자만 보여 눌러지는 것처럼 보이지 않게 한다. 방을 연 사람은 `개설자` 글자 대신 직접 그린 왕관(방장) 아이콘(`shared-room.js`의 `CROWN`, 코드 안의 SVG)으로 표시하고, 대화 글의 이름 옆에도 같은 아이콘을 쓴다. 모달은 제목(위)과 [방 나가기]·[일찍 끝내기]·[모닥불 취소] 같은 버튼(아래)을 고정하고 가운데만 스크롤하며, 스크롤바는 광장 채팅·공유방 대화·모든 모달이 같은 얇고 둥근 공통 모양을 쓴다. **책 제목은 한 화면에 한 번만 쓴다**: 장면에서는 위 제목줄, 마을 모달에서는 창 제목이 맡고 그 아래 안내줄·카드·방 정보에 다시 쓰지 않는다. 대화창을 접은 버튼도 `💬 대화 열기`만 쓴다 | 대화창을 접은 상태에서도 배경 버튼으로 모달을 열 수 있다. 마을 모달(종료된 방, 예정 방, 입장 전 확인)에는 배경 버튼이 없어 탭을 그대로 쓴다. 각자 읽기 방은 내가 읽는 책이 방 이름에 없으면 안내줄과 방 정보에 책 이름을 보인다. 책장의 책 상세 공유방 탭 카드는 책 이름을 빼고 `이야기방` 등으로 보인다. 방 이름 입력칸의 안내 글에도 책 이름을 쓰지 않는다. 아이콘은 왕관과 같은 단순한 윤곽선 그림이고, 노란 ✦는 알림 전용이라 버튼에는 쓰지 않는다 |
| RC-23 | **모닥불 시간제**: 진행 시간은 1~7시간이고 시간이 다 되면 저절로 종료되어 장면에 있던 사람은 광장으로 돌아온다("모닥불이 꺼졌어요. 광장으로 돌아왔어요"). 장면에 머문 시간은 오늘 읽은 시간에 더하며 스탠드 기록과 겹치는 구간은 한 번만 센다 | 결정 #53. 1분 미만은 기록하지 않는다. 장면을 열어 둔 채 새로고침하면 그 시간은 기록되지 않는다 |
| RC-22 | **각자 읽기 방 표시**: 대화창 부제는 책 제목 대신 `각자 읽기 · 참여 n/max명 · …`. 모닥불 장면 이름표는 `@나무 『모순』`처럼 이름 옆에 읽는 책을 붙이고, 제목이 8자를 넘으면 맨 앞 단어만 보인다. 닉네임은 최대 5자(입력 화면은 아직 없음) | 결정 #52. 같은 책 방은 지금처럼 부제에 `『책』`을 둔다 |

**이번 단계에 넣지 않는 것**: 소파 메모·인용 첨부 보내기, 모닥불 곁 말풍선(마을에서 모닥불 근처에 가면 최근 글이 말풍선으로 뜨는 것), 글 공감, 답글·멘션, 이미지, 글 검색, 개설자의 글 숨김·내보내기, 신고·차단(공개 가입 전에 추가, #41).

**서버 대응**: `room_message`(`page` 컬럼 추가. 삭제 기능은 폐지돼 `deleted_at`은 쓰지 않는다), `room_participant`(`agreed_at`, `last_read_at`, `left_at` 추가). API: `GET/POST /rooms/{id}/messages`, `POST /rooms/{id}/read`, `DELETE /rooms/{id}/participants/me`(기존).
