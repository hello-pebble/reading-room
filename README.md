# 독서 공유방 (reading-room)

복셀 아이소메트릭 스타일의 독서 기록·공유 웹서비스.
**내 방**에서 혼자 기록하고, **마을**에서 같은 책을 읽은 사람들과 이야기한다.

> 마지막 정리: 2026-11-16

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `README.md` | 지금 이 문서. 개요, 진행 상태, 다음 할 일 |
| `SPEC.md` | 확정된 기능 명세 (방, 가구, 타이머, 거울, 마을, 공유방, 계정, 온보딩) |
| `DATA_API.md` | 테이블 설계, API, 배치 작업 |
| `DECISIONS.md` | 결정 기록과 아직 열려 있는 결정 |
| `FEATURE_DEFINITION.md` | 내 방 기능 정의서 (기능 ID, 동작, 규칙·예외, 데이터, 제약) |
| `FEATURE_GUIDE.md` | 내 방 기능 설명서 (사용자용 사용법) |
| `prototype/index.html` | 클릭해서 테스트할 수 있는 내 방 프로토타입. 3D 유령 + 원목 방. 인터넷 없이도 열림 (`prototype/vendor/three.min.js` 함께 필요) |
| `prototype/vendor/three.min.js` | 3D 라이브러리 three.js r149 (MIT, 약 0.6MB). 오프라인용으로 함께 둠 |
| `prototype/index-voxel.html` | 이전 복셀 캐릭터 버전 (SVG, 외부 의존성 없음). 되돌릴 때 사용 |
| `prototype/dolls.html` | 유령 단독 시안 (표정·장식·소품을 고르며 걸어다니는 확인용) |

## 출시 순서

| 단계 | 내용 |
|---|---|
| 1. 친구 베타 | 웹(PWA), 초대 링크 + 카카오 로그인 |
| 2. 웹 출시 | 공개 가입 |
| 3. 앱 전환 | Capacitor로 웹 화면 재사용 + 네이티브 기능(라이브 액티비티, 로컬 알림, 위젯) |
| 4. 상용화 이후 | 가구 꾸미기(스킨), 데스크톱 앱(투명 창 캐릭터) |

## 마을 확장 후보 (미확정)

| 안 | 내용 | 걸리는 점 |
|---|---|---|
| 모닥불 곁 말풍선 | 불 가까이 가면 최근 대화가 뜨고 바로 한 줄 남김 | 쪽수 잠금 방은 내 쪽수까지만 보여야 함 |
| 광장 한 줄 채팅 | 책이 달라도 광장에서 짧게 대화 | 공개라 신고·관리 필요 (열린 결정 M), 1~2일 뒤 삭제 |
| 이웃 쪽지·방문 | 이웃집 노크, 방 구경만 | 하루 횟수 제한 |
| 실제 불 켜진 창문 | 스탠드를 켠 사람의 집 창문이 켜짐 | 서버 필요 |
| 계절 행사 | 연말 "올해 읽은 책" 모닥불 등 | 나중에 |

공통: 서버가 있어야 하고, 퀵바 없이 모닥불·광장·이웃집 앞에서만 입력창이 열리며, 알림은 노란 ✦만 쓴다.

## 프로토타입 테스트

- `prototype/index.html`을 크롬이나 엣지로 직접 연다. (claude.ai 링크에서는 바탕화면 띄우기가 막힐 수 있음)
- 모바일 구도는 창 폭을 760px 이하로 줄이거나 폰에서 열면 나온다.
- 데이터는 브라우저 localStorage(`myroom-proto-v1`)에 저장되고, 오른쪽 위 **데모 초기화**로 되돌린다.
- 첫 방문 안내(소파를 눌러 책을 올려보세요)는 평소에 뜨지 않고, **데모 초기화**를 눌렀을 때만 시작된다.
- 스탠드가 켜진 상태에서 패널 아래 **테스트 도구**로 +10분, +60분(확인 알림), +3시간(깜빡함)을 흉내 낼 수 있다.
