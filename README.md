# 독서 공유방 (reading-room)

3D 유령 + 원목 방 아이소메트릭 스타일의 독서 기록·공유 웹서비스.
**내 방**에서 혼자 기록하고, **마을**에서 같은 책을 읽은 사람들과 이야기한다.

> 마지막 정리: 2026-11-17

## 프로토타입 테스트

- `prototype/index.html`을 크롬이나 엣지로 직접 연다. (claude.ai 링크에서는 바탕화면 띄우기가 막힐 수 있음)
- 모바일 구도는 창 폭을 760px 이하로 줄이거나 폰에서 열면 나온다.
- 데이터는 브라우저 localStorage(`myroom-proto-v1`)에 저장되고, 오른쪽 위 **데모 초기화**로 되돌린다.
- 첫 방문 안내(소파를 눌러 책을 올려보세요)는 평소에 뜨지 않고, **데모 초기화**를 눌렀을 때만 시작된다.
- 스탠드가 켜진 상태에서 패널 아래 **테스트 도구**로 +10분, +60분(확인 알림), +3시간(깜빡함)을 흉내 낼 수 있다.

### 자동 검사 (`npm run verify`)

- `npm install`(처음 한 번) 뒤 `npm run verify`로 **문법 검사 + 시나리오 테스트 22개**(약 2초)를 돌린다. 코드를 바꿀 때마다 돌리고, 통과해야 커밋한다.
- `tests/check-syntax.js`는 `prototype/*.html`의 인라인 스크립트 문법을, `tests/scenarios.test.js`는 페이지를 가상 브라우저(jsdom)에 올려 타이머·기록·쪽수·완독일·광장 대화·공유방 가져오기·거울·키보드 같은 규칙을 실제로 조작해 확인한다. 지금까지 겪은 결함(3시간 확인 우회, 날짜 기준, 쪽수 범위, 셔플 색, 가져오기 책 처리 등)이 되돌아오지 않게 막는 용도다.
- 테스트는 3D를 올리지 않아서 **3D 그림, 터치, 알림 팝업, 화면 겹침**은 못 본다. 이런 것은 브라우저로 직접 확인한다.
- `AGENTS.md`는 자동으로 일하는 에이전트(예: Ralph, 클라우드 세션)가 읽는 작업 지침이다.
