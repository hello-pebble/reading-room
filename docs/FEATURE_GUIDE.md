# 내 방 기능 설명서

내 방은 책을 읽고 기록하는 나만의 공간이에요. 방 안의 가구를 눌러서 책을 올리고, 읽은 시간을 재고, 지난 기록을 보고, 나를 꾸밀 수 있어요.

화면 색상이나 문구를 직접 바꾸려면 [수정 안내](../frontend/EDITING.md)를 보세요. 공용 스타일과 내 방·마을·공유방 전용 스타일, 기능별 수정 위치를 정리했어요.

## 1. 시작하기

### 화면 구성

| 위치 | 내용 |
|---|---|
| 맨 위 | 내 얼굴, "○○의 방", 읽은 책 권수·연속 기록·오늘 읽은 시간 |
| 가운데 | 원목 방. 방 안에 내 유령이 있어요 |
| 가구 | 소파, 스탠드, 책장, 달력, 거울, 창문, 문 |

### 기본 조작

| 하고 싶은 일 | 방법 |
|---|---|
| 가구 사용하기 | 가구를 눌러요. 화면 가운데에 창이 열려요 |
| 유령 움직이기 | 바닥을 누르면 그 자리로 걸어가요 |
| 창 닫기 | 오른쪽 위 ✕, 창 바깥, 또는 키보드 ESC |
| 가구 이름 보기 | 마우스를 올리면 이름과 상태가 떠요. 터치 화면은 처음 들어올 때 가구가 차례로 반짝여요 |

방 크기는 바뀌지 않아요. 휴대폰처럼 좁은 화면에서는 방이 조금 작은 구도로 보여요.

### 알림은 노란 별이에요

가구에 노란 별(✦)이 깜빡이면 확인할 새 소식이 있다는 뜻이에요. 그 가구를 열면 별이 사라져요.

| 노란 별이 뜨는 곳 | 의미 |
|---|---|
| 거울 | 새로 쓸 수 있는 꾸미기 아이템이 생겼어요 |
| 창문 | 내 서재로 가져와야 할 종료된 공유방이 있어요 |
| 소파 | 소파가 비어 있어요. 읽을 책을 올려 보세요 (책을 올리면 사라져요) |

## 2. 가구별 사용법

### 소파 · 지금 읽는 책

소파에는 한 번에 한 권만 올릴 수 있어요.

| 단계 | 하는 일 |
|---|---|
| 1. 책 올리기 | 소파를 누르고 [책 찾기]에 책 제목이나 저자를 넣고 [찾기]. 나온 목록에서 표지를 보고 책을 고르면 표지, 제목, 저자, 쪽수가 한 번에 채워져요. 그다음 [소파에 두기] |
| 2. 읽는 중 | 소파를 누르면 표지와 함께 "현재 쪽 / 전체 쪽"을 적는 칸이 있어요. 쪽수를 적으면 퍼센트가 자동으로 계산되고 바로 저장돼요 |
| 3. 메모 남기기 | 메모나 인용구를 고르고 내용을 적어요. 쪽수는 비워도 돼요. 쪽수를 적으면 지금까지 읽은 쪽보다 클 때 현재 쪽과 퍼센트가 자동으로 올라가요. [추가]를 누르면 쌓여요 |
| 4-가. 다 읽었을 때 | [완독] → 별점과 한줄평(둘 다 안 써도 돼요) → [책장에 꽂기] |
| 4-나. 포기할 때 | [포기] → 확인. 책은 책장의 "포기한 책"으로 가고 메모는 그대로 남아요 |

소파를 누르면 유령이 걸어가서 소파에 앉아요.

책을 찾을 때 알아두면 좋은 점이에요.

- 인터넷이 없거나 책을 못 찾으면 제목과 저자를 직접 적으면 돼요. 전체 쪽수는 비워 두어도 되지만, 적어야 퍼센트가 계산돼요.
- 없는 책이면 제목·저자를 직접 적을 수 있어요. 한국 책은 못 찾는 경우가 있어요.
- 서점 책 링크를 붙여 넣어도 찾아 주지만, 링크 모양이 달라 못 찾는 경우도 있어요. 그럴 때는 제목으로 찾아 보세요.
- 한국 책은 못 찾는 경우가 있어요. 정식으로 서비스할 때는 더 잘 찾도록 개선할 예정이에요.

### 스탠드 · 독서 타이머

스탠드는 책을 읽는 시간을 재요. 켜져 있는 동안 불이 들어오고 바닥에 빛이 퍼져요.

| 하고 싶은 일 | 방법 |
|---|---|
| 읽기 시작 | 스탠드를 누르고 [스탠드 켜고 읽기 시작]. 소파에 책이 있어야 해요 |
| 지금 시간 보기 | 스탠드 위 이름표, 스탠드 창, 맨 위 헤더에서 볼 수 있어요 |
| 읽기 끝내기 | 스탠드를 누르고 [💡 스탠드 끄기] → 현재 쪽(퍼센트가 바로 보여요), 한 줄 메모(안 써도 돼요) → [끄고 저장] |
| 저장 안 하고 끄기 | 스탠드 창 아래 [기록 안 하고 끄기] |
| 밖에서 읽었을 때 | 스탠드가 꺼져 있을 때 [밖에서 읽었어요 · 직접 기록]. 오늘이나 어제, 읽은 분을 적어요 (1~600분) |
| 지난 기록 보기 | 스탠드 창에서 이 책에 읽은 시간, 오늘 읽은 시간, 최근 기록 5개를 볼 수 있어요 |

알아두면 좋은 점은 아래와 같아요.

- 화면을 꺼도, 창을 닫아도 시간은 계속 재요. 다시 열면 켠 시각부터 다시 계산해요.
- 1분보다 짧게 읽으면 기록하지 않아요.
- 일시정지는 없어요. 끄고 다시 켜면 새 기록이 하나 더 생겨요.
- 완독이나 포기를 하면 켜져 있던 스탠드는 자동으로 꺼지고 기록돼요.
- 인터넷이 없어도 스탠드로 시간을 재고 기록할 수 있어요. 기록은 기기에 저장돼요.

#### 끄는 걸 깜빡했을 때

| 상황 | 일어나는 일 | 해야 할 일 |
|---|---|---|
| 60분이 지났어요 | 알림으로 "아직 읽고 있어요?"가 오고, 화면 아래에도 떠요 | [계속]이면 이어서 재고(60분 뒤 다시 물어요), [스탠드 끄기]면 끝내요 |
| 3시간이 넘었어요 | 기록을 잠시 멈추고 "확인 필요"로 바뀌어요. "확인이 필요해요" 알림이 오고, 방 아래에 [확인하기]가 떠요 | 마지막으로 '계속'을 누른 시각까지 / 직접 입력 / 기록 안 함 중 골라요 |

#### 알림 켜기

스탠드를 처음 켤 때 브라우저가 알림을 허용할지 물어봐요. 허용하면 위의 알림을 받을 수 있어요. 스탠드 창의 [알림 켜기]에서도 켤 수 있어요.

- 알림은 이 페이지를 열어 둔 동안에 와요. 창을 닫으면 오지 않아요.
- 알림을 허용하지 않았거나 지원하지 않는 브라우저에서는 화면 안내로만 알려줘요.
- 한번 거부했다면 주소창 옆 자물쇠에서 알림을 허용해 주세요.

#### 바탕화면에 띄우기

스탠드가 켜져 있을 때 [바탕화면에 띄우기]를 누르면 작은 창이 따로 떠요. 소파에 앉은 유령과 읽은 시간이 보이고, 그 창의 스탠드를 누르면 꺼지면서 저장돼요.

- 데스크톱 크롬·엣지, 파이어폭스(151 이상)에서만 쓸 수 있어요.
- 휴대폰과 사파리에서는 이 버튼이 보이지 않아요.

### 책장 · 읽은 책

다 읽은 책이 책장에 꽂혀요. 책장은 위 칸부터 채워지고, 칸 안에서는 왼쪽부터 꽂혀요. 책장에는 책이 28권(휴대폰은 24권)까지 보여요. 그보다 많이 읽었다면 가장 최근에 다 읽은 책부터 그 수만큼 꽂히고, 오래된 책은 책장을 눌러 열리는 목록에서 볼 수 있어요. 책장 화면에는 다 읽은 책, 포기한 책, 나중에 읽을 책 탭이 있어요. "나중에 읽을 책"에는 공유방에서 기록을 가져왔는데 내 책장에 없던 책이 담겨요. 그 책을 소파에 올리면 이 목록에서 빠지고 공유방 기록이 그대로 따라와요.

| 하고 싶은 일 | 방법 |
|---|---|
| 책 목록 보기 | 책장을 누르면 [다 읽은 책]과 [포기한 책] 탭이 있어요 |
| 책 자세히 보기 | 책을 누르면 [기록], [한줄평] 탭이 있어요. 공유방에서 가져온 대화가 있으면 [공유방] 탭도 생겨요 |
| 목록으로 돌아가기 | [← 목록] |

### 달력 · 독서한 날과 목표

벽에 걸린 달력을 누르면 이번 달을 볼 수 있어요. (한국 시간 기준이에요.)

| 보이는 것 | 설명 |
|---|---|
| 초록색에 점이 있는 날 | 스탠드를 끄며 시간을 저장했거나(직접 기록 포함), 책을 완독한 날이에요 |
| 테두리가 있는 날 | 오늘이에요 |
| 연속 독서일 | 오늘 또는 어제부터 이어서 읽은 날 수예요. 같은 날 여러 번 읽어도 하루로 세요. 어제도 오늘도 안 읽었다면 0일이에요 |
| 이번 달 완독 목표 | 한 달에 몇 권을 다 읽을지 정해요. 달마다 따로 저장돼요 |
| 달성 현황 | `완독 2/3권`처럼 그 달에 다 읽은 책과 목표를 같이 보여줘요. 포기한 책은 세지 않아요 |
| ‹ › 버튼 | 지난 달 달력을 볼 수 있어요. 지난 달에는 그 달의 목표와 결과(`목표 달성`/`목표 미달성`)가 보여요 |

목표 바꾸기: [−], [+]를 누르거나 숫자를 직접 적어요(입력칸 안의 위아래 버튼은 없어요). 저장 버튼은 따로 없어요. 처음에는 1권이고, 1권부터 99권까지 정할 수 있어요. 바꾸면 바로 저장돼요.

- **이번 달 목표만 바꿀 수 있어요.** 바꿔도 지난 달 목표는 그대로예요. 지난 달 기록이 나중에 달라지지 않아요.
- 새 달이 되면 지난 달 목표를 그대로 이어받아요. "지난 달 목표를 이어받았어요"가 보이고, 바꾸고 싶을 때만 바꾸면 돼요.
- 달 중간에 목표를 바꾸면 `🔁 목표를 바꿨어요 · 3→4권 (11.17)`이 남아요. 같은 날 여러 번 눌러도 한 번으로 보고, 처음 값으로 되돌리면 사라져요. 지난 달을 볼 때도 보여요.
- 달력을 처음 쓰기 전의 달은 "목표 기록 없음"으로 보여요.

방 안의 달력에도 이번 달과 독서한 날, 완독 현황이 같이 그려져요.

### 거울 · 나 꾸미기

거울을 누르면 왼쪽에 내 모습, 오른쪽에 고를 수 있는 항목이 나와요. 거울 속에 내가 비치지는 않아요.

| 항목 | 고를 수 있는 것 |
|---|---|
| 색상 | 하양, 크림, 분홍, 민트, 하늘, 라일락, 버터, 회색 |
| 표정 | 기본, 웃음, 놀람, 졸림, 윙크 |
| 얼굴 장식 | 없음, 동그란 안경, 선글라스, 반창고 |
| 머리 장식 | 없음, 비니, 리본, 왕관, 새싹 |
| 손에 든 소품 | 없음, 책, 찻잔, 랜턴, 풍선 |

- 고르면 미리보기와 방 안의 유령, 맨 위 얼굴이 바로 바뀌어요. 마음에 들면 [저장], 아니면 [취소]를 눌러요. 저장하기 전에는 원래 모습이 그대로예요.
- 위쪽 교차 화살표 버튼(셔플)을 누르면 모든 항목이 무작위로 바뀌어요.
- 잠긴 항목이 있어요. 동그란 안경은 첫 책을 기록한 뒤, 비니는 책을 10권 읽은 뒤에 열려요.
- 꾸민 모습은 마을과 공유방에서도 보여요.

### 창문 · 공유방 소식

창문 유리에는 창밖 풍경이 보여요. 계절에 맞는 풍경이고, 날씨(맑음, 구름, 흐림, 비, 눈, 안개)는 날마다 바뀌어요. 창문을 누르면 맨 위에 "오늘 창밖은 가을 비예요"처럼 오늘의 풍경이 적혀 있어요.

창문을 누르면 공유방 소식이 카드로 나와요.

| 상태 | 할 수 있는 일 |
|---|---|
| 진행 중 | [마을로 가기] |
| 예정 | [알림 받기]를 켜면 방이 열릴 때 알림이 와요. 알림을 누르면 창문이 열려요. 다시 누르면 꺼져요 |
| 종료 | [내 서재로 가져오기]. 공유방 대화가 책장의 그 책 [공유방] 탭에 담겨요. 그 책이 내 책장에 없으면 책장의 "나중에 읽을 책" 목록에 담겨요 (다 읽은 책으로 세지 않아요) |

- 공유방 기록은 종료 후 7일 동안만 보관돼요. 그 안에 가져와야 해요.
- 가져온 대화 속 다른 사람은 "참여자 A"처럼 이름 없이 보관돼요.

### 문 · 마을로 나가기

문을 누르면 유령이 문으로 걸어가서 마을로 나가요.

## 마을

마을은 방과 달리 한눈에 다 보이지 않는 큰 마을이에요. 화면이 유령을 따라다녀서, 바닥을 눌러 걸어 다니며 둘러보면 돼요. 키보드가 있으면 **방향키나 WASD**를 누르고 있는 동안 그쪽으로 걸어요(채팅을 치는 중에는 걷지 않아요). 지도를 누르고 끌면 유령은 그대로 있고 지도만 움직여서 다른 곳을 미리 볼 수 있어요. 다시 걸어가면 화면이 유령을 따라와요.

| 있는 것 | 하는 일 |
|---|---|
| 내 방(집) | 누르면 걸어가서 방으로 돌아와요 |
| 마을 게시판 | 광장 위쪽에 있어요. 누르면 열린 방, 곧 열릴 방, 지난 방이 한꺼번에 나와요. 열린 방은 [들어가기], 예정 방은 [알림 받기], 지난 방은 [내 서재로 가져오기]예요 |
| 접속 인원 | 화면 아래쪽에 연하게 `접속 (06/100)`이 떠요. 지금 마을에 와 있는 사람 수와 들어올 수 있는 최대 인원이에요 (체험판은 예시). 마을이 가득 차면 초대 링크로 오는 친구도 잠시 기다려야 해요. 그래도 내 방은 그대로 쓸 수 있어요 |
| 미니맵 | 오른쪽 위의 작은 정사각형 지도예요. 위에서 내려다본 모양이고, 화면의 방향과는 달라요. 마을 전체와 내 위치(노란 점)가 보여요. 보기만 하는 지도라 눌러도 움직이지는 않아요 |
| 광장 | 가운데 돌바닥 구역이에요. 안으로 들어가면 이웃과 이야기할 수 있는 채팅창이 떠요 |
| 모닥불 구역 | 동쪽 흙바닥 구역이에요. 공유방마다 모닥불이 하나씩 있고, 누르면 그 방의 정보가 나와요 |
| 이웃집 | 집을 눌러 방문하고 책장에 추천 책을 꽂아 둘 수 있어요. 집 주인에게는 내 닉네임이 함께 보여요. 불빛은 다른 사람들이 읽는 분위기를 보여줘요 |

### 이웃집에 책 추천하기

1. 마을에서 이름이 붙은 이웃집을 눌러 들어가요. 분홍 체크무늬 벽지 배경에 책장과 내 캐릭터만 가운데 크게 보여요.
2. 책장을 누르고 추천할 책 옆의 [책 꽂기]를 눌러요. 지금 읽는 책과 다 읽은 책만 고를 수 있어요.
3. 창이 닫히고 책장 아래 칸으로 책 한 권이 들어가요. 내 책은 그대로 남아요.
4. 집 주인이 확인할 때까지 한 집에 한 권만 둘 수 있어요. 다른 집에도 추천할 수 있고, 왼쪽 위의 초록색 [← 마을로]로 나올 수 있어요.
5. 집 주인이 확인하면 아래 칸이 비어서 다시 추천할 수 있어요.

체험판에서는 이웃집 책장의 [테스트 도구 → 집 주인 시점으로 보기 → 확인했어요]로 확인을 재현해요. 내 집에 도착한 추천은 책장의 노란 별과 추천 카드로 확인하고 [확인했어요]로 비울 수 있어요. 실제 다른 사용자에게 전달하는 기능은 서버 연결 뒤 제공해요.

### 광장에서 이야기하기

방에 들어가지 않아도, 책이 달라도 괜찮아요. 광장에 온 이웃과 한 줄로 짧게 이야기해요.

1. 마을에 들어서면 화면에 **반투명 채팅창**이 저절로 떠요(PC는 왼쪽에 화면 높이만큼 세로로 길게, 폰은 아래쪽). 마을 어디에 있어도 보여요. 광장 가운데 분수대를 누르면 그 앞으로 걸어가요.
2. 입력칸에 글(300자까지, 공유방 대화와 같아요)을 적고 [보내기]를 눌러요. Enter도 돼요.
3. 내 머리 위에 말풍선이 잠깐 떠요. 이웃의 말은 그 이웃 머리 위에 떠요.

- 채팅창은 마을에 있는 동안 계속 보여요. 내 방이나 모닥불로 가면 사라져요.
- 채팅창 제목(`💬 광장 이야기`)을 누르면 접어 둘 수 있어요. 마을을 넓게 보고 싶을 때 써요.
- 글은 하루 뒤에 사라져요.
- 공유방 이야기는 모닥불 구역의 모닥불 안에서 해 주세요.

모닥불은 공유방의 상태를 보여줘요.

| 모닥불 모양 | 뜻 |
|---|---|
| 활활 타요 | 지금 열려 있는 방이에요 |
| 불이 안 붙었어요 | 아직 열리지 않은 방이에요. 열리면 불이 붙어요 |
| 마을에 없어요 | 끝난 방은 마을에 불이 없어요. 마을 게시판의 "지난 방"에서 7일 동안 볼 수 있고, 그 전에 내 서재로 가져오세요 |
| 파란 불 | 이미 내 서재로 가져온 방이에요 |

### 모닥불에서 이야기하기 (공유방 대화)

참여자·방 정보 버튼은 마을로 버튼과 같은 크림색이고, 대화창과 같은 반투명 배경을 써요. 아이콘은 윤곽선 없이 보여요.

마을 게시판의 [들어가기]나 모닥불을 누르면 대화 화면이 열려요.

1. 처음 들어갈 때 한 번 안내가 떠요. "글은 종료 후 7일 뒤 사라져요, 가져가면 다른 사람 이름은 참여자 A로 바뀌어요." [동의하고 들어가기]를 누르면 들어가요.
2. 모닥불 안에서는 대화창에 대화만 있어요. 대화창 옆의 동그란 버튼(사람 여러 명 모양은 참여자, i 모양은 방 정보)을 누르면 대화창과 따로 창이 떠요. 그 창의 ✕나 Esc는 그 창만 닫아요(모닥불을 나가려면 대화창의 ✕를 눌러요). 참여자는 바둑판처럼 나란히 보이고 방을 연 사람(방장)은 이름 옆에 왕관 아이콘이 붙어요. [일찍 끝내기] 같은 버튼은 아래에 고정돼 있어요. 마을 게시판에서 여는 종료된 방은 위쪽 탭 [대화] [참여자] [방 정보]로 보여요. 방 정보에는 초대 링크와 개설자의 [일찍 끝내기]가 있어요.
3. 아래 입력칸에 글을 적고 [보내기]를 눌러요(300자까지. 3초에 3번까지 보낼 수 있고, 같은 말을 연달아 보내는 것은 30초 동안 막혀요). 컴퓨터에서는 Enter로도 보내고 줄바꿈은 Shift+Enter예요. 폰에서는 Enter가 줄바꿈이고 [보내기]로 보내요.
4. 글을 보내거나 받으면 모닥불에 앉은 그 사람의 머리 위에 말풍선이 몇 초간 떠요.
5. ✕나 [← 마을로]를 누르면 "모닥불에서 나갈까요?"라고 한 번 물어요. [마을로 나가기]를 눌러야 마을로 돌아가고, 방에서 나가는 건 아니라서 대화는 그대로 남아요.

**쪽수와 스포일러**: 같은 책 방에서 글에는 내 현재 쪽(소파에 적은 쪽)이 `📖 124쪽`으로 자동으로 붙어요. 칩을 눌러 고치거나 뺄 수 있어요. 대화는 전부 보여요. 아직 읽지 않은 책이면 들어가기 전에 "줄거리나 결말이 나올 수 있어요"라고 알려 주고, 대화 위에 `📖 안 읽은 책 · 스포 주의` 띠가 있어요. 내용을 보고 마음에 들면 띠의 [나중에 읽을 책에 담기]를 눌러 보세요. 다 읽었거나 포기한 책이면 안내가 없어요.

- 내 글은 ⋯ 를 눌러 삭제할 수 있어요. 방을 나가면 내 글은 남고 "나간 참여자"로 보여요.
- 다른 사람이 얼마나 읽었는지(퍼센트)는 보이지 않아요. 글에 붙은 쪽수만 보여요.
- 안 읽은 글이 있으면 마을의 모닥불 위와 창문에 노란 별(✦)이 떠요. 방을 열면 사라져요.
- 방이 끝나면 대화는 읽기만 돼요. 위쪽 띠에 남은 날(D-5)이 보이고 [내 서재로 가져오기]를 누를 수 있어요. 끝난 방은 마을 게시판 "지난 방"에 7일 남았다가 사라져요.

### 모닥불 피우기 (공유방 만들기)

마을에서 불이 없는 빈 모닥불 자리("+ 모닥불 피우기")나 마을 게시판의 [모닥불 피우기]를 누르면 직접 공유방을 만들 수 있어요.

| 고르는 것 | 설명 |
|---|---|
| 방 종류 | **같은 책**: 모두 같은 책을 읽어요. 쪽수에 맞춰 이야기해요. **각자 읽기**: 서로 다른 책을 읽으면서 같이 이야기해요 |
| 이름표 | 각자 읽기 방에서는 모닥불 이름표에 `@나무 『모순』`처럼 읽는 책이 같이 보여요. 제목이 길면 맨 앞 단어만 보여요 |
| 책 | 지금 소파에서 읽는 책, 책장의 책, 직접 입력 중에서 골라요. 각자 읽기는 아직 안 정해도 돼요 |
| 방 이름 | 비워 두면 자동으로 지어져요 |
| 시작 | 지금 바로 열거나, 날짜와 시각을 정해 예약해요 |
| 진행 시간 | 1~7시간 (기본 3시간). 시간이 다 되면 모닥불이 저절로 꺼지고 모두 광장으로 돌아가요. 모닥불에서 이야기하며 읽는 시간은 오늘 읽은 시간에 더해져요 |
| 초대 | 초대 링크나 초대 코드를 받은 친구만 들어올 수 있어요. 다른 사람이 피운 모닥불도 마을에 보이지만, 들어가려면 그 사람에게 초대 코드를 받아야 해요 |
| 최대 인원 | 2~10명 |
| 스포 안내 | 같은 책일 때만. 안 읽은 책이면 입장 전에 알려 줘요 |

- **친구가 같은 책을 안 읽어도 돼요.** 이럴 때는 "각자 읽기"로 만드세요. 각자 읽는 책 이야기를 나누고, 끝나면 내가 고른 책에 대화가 담겨요.
- 만들면 **초대 링크**가 나와요. 링크 칸 옆의 복사 버튼(겹친 사각형 모양)이나 공유 버튼으로 친구에게 보내면, 링크를 연 친구가 그 모닥불로 들어와요. 방 정보(모닥불의 i 버튼)에는 **초대 코드**와 [코드 복사] 버튼도 있어요. 코드를 받은 친구는 마을 게시판의 [초대 코드로 입장]을 누르고 8자리 코드를 적은 뒤 [확인]을 눌러요. 방 이름·책·진행 시간·참여 인원을 보고 [이 방에 입장]을 누르면, 보관 동의를 거쳐 모닥불로 들어가요. 코드가 틀렸거나 끝난 방이면 입력칸 아래에 이유가 나와요.
- 동시에 열 수 있는 모닥불은 2개이고, 하루에 3번까지 피울 수 있어요(취소해도 한 번으로 세요). 3번을 다 쓰면 다음날 피워요. 예약한 모닥불은 [모닥불 취소], 열린 모닥불은 [일찍 끝내기]로 닫을 수 있어요. 보낸 글은 삭제하거나 고칠 수 없으니 보내기 전에 확인하세요.
- 기간이 끝나면 모닥불이 작아지다가 7일 뒤에 꺼지고 사라져요.
- 체험판에서는 서버가 없어서 이 브라우저에서 만든 모닥불만 링크로 열려요. 친구가 들어오는 건 모닥불 창의 [테스트 도구]에서 흉내 낼 수 있어요.
- 방 크기는 2명부터 10명까지 정할 수 있어요. 처음에는 8명이에요.
- 가져온 기록은 방이 사라져도 책장에 그대로 남아요.
- 화면 폭을 바꾸면 마을에서 방으로 돌아와요.

| 시간이 안 맞는 것 같아요 | 화면 숫자는 보여주기용이에요. 시작한 시각부터 계산하기 때문에 다시 열면 맞춰져요 |
| 처음 상태로 돌리고 싶어요 | 오른쪽 위 [데모 초기화] (체험판에만 있어요) |

## 6. 체험판 안내
