# 기능 명세

프로토타입의 기능은 `frontend/js/room.js`(내 방)·`village.js`(마을)·`shared-room.js`(공유방)로 나눈다(내 방과 공유방, 공용 코드는 구역별 파일로 더 나뉜다: 결정 #70). 스타일은 `common.css`(공용)·`room.css`·`village.css`·`shared-room.css`로 나눈다. 3D는 `scene.js`, 공용 상태·저장·모달과 각 기능의 시작 순서는 `app.js`에 둔다. 기능 규칙과 저장 형식은 유지한다. 직접 수정할 위치는 [수정 안내](../frontend/EDITING.md)를 본다.

## 1. 내 방

### 원칙
- 가구 하나에 역할 하나. **퀵바 없이 가구를 눌러서** 사용한다.
- 방 크기는 절대 바뀌지 않는다. 확대 연출과 패널 때문에 방이 줄어드는 레이아웃은 쓰지 않는다.
- 입력은 **화면 가운데 모달**로 띄운다. 제목과 ✕는 위에, 액션 버튼은 아래에 고정하고 가운데만 스크롤한다.
- 닫기: ✕, 바깥 클릭, ESC.
- 지금 단계에서는 가구를 늘리지 않는다. 가구 꾸미기(스킨)는 상용화 이후.

### 화면 구도

| 환경 | 방 | 비고 |
|---|---|---|
| 데스크톱 (폭 761px 이상) | 10×8칸, 카메라 기본 | 책장 책 28권까지 보임 |
| 모바일 (폭 760px 이하) | 7×6.5칸, 카메라를 세워 방이 화면 폭을 채움 | 가구 종류·배치 순서는 같고 간격만 좁힘. 책장 책 24권까지 보임. 방은 화면 세로 중앙에 놓임. **여백 없이 화면을 가득 채운다**: 바깥 간격과 둥근 테두리가 없고, 헤더는 얇은 띠이며 방·마을 화면이 나머지 전체를 쓴다 |

내 방은 벽 높이까지 포함한 방 전체가 화면 세로 가운데에 오도록 카메라 목표 높이를 2.1에 둔다(윗부분이 잘리지 않게, 2026-11-18). 데스크톱·모바일 모두 같다.

방과 캐릭터는 three.js로 그린 3D이고, 카메라는 고정된 아이소메트릭 각도다. 그림 스타일은 **툰 셰이딩**(#37)이다: 빛을 3단계로 끊어 칠하고 물체마다 얇고 연한 갈색 외곽선을 두른다(눈·볼 같은 작은 조각과 마을의 나무는 외곽선 없음). 바닥·벽·책장·문은 원목 질감이고 확대 연출은 쓰지 않는다. 창 크기가 기준선을 넘나들면 방이 다시 그려지고 캐릭터는 시작 위치로 돌아간다. 바탕화면 창, 거울 미리보기, 헤더 아바타는 어느 구도에서나 같은 모양이다.

### 가구

| 가구 | 위치 | 역할 | 상태 연출 |
|---|---|---|---|
| 책장 | 왼쪽 벽 앞쪽 절반 | 과거: 다 읽은 책, 포기한 책, 책별 기록·한줄평·공유방 탭 | 권수만큼 책등이 채워짐. 맨 위 칸부터, 칸 안에서는 왼쪽부터 꽂힘 |
| 소파 | 러그 위 중앙 | 현재: 읽는 책 1권, 쪽수·퍼센트, 메모·인용구, 완독·포기 | 비면 쿠션만, 읽는 중이면 펼친 책 |
| 스탠드 | 소파 옆 바닥 | 독서 타이머 | **타이머가 돌 때만** 불이 켜지고 바닥에 빛이 퍼짐, 위에 경과 시간 표시 |
| 전신거울 | 뒷벽, 예전 책상 자리 (문 옆) | 캐릭터 꾸미기 | 새 아이템이 있으면 노란 별 |
| 창문 | 뒷벽, 소파 정면 위 | 진행 중·예정·종료된 공유방, 가져오기 마감일 (화면에는 "창문"이라는 이름만 표시) | 계절(월)과 날씨(날짜마다 무작위로 바뀜)를 그린 창밖 풍경. 시간대는 고정. 인터넷 없이도 바뀜 |
| 문 | 오른쪽 벽 (가구 아님) | 마을로 나가기 | 없음 (열린 공유방은 창문에서 확인) |

책상은 제거했다. 책상의 쓰기 기능은 소파의 "읽는 중" 단계로 합쳤다.

### 달력

왼쪽 벽, 책장 옆(책장이 반으로 줄어 생긴 자리)에 건다. 책장은 책 28권(모바일 24권)까지 보인다. 그보다 많으면 **가장 최근에 다 읽은 책 28권(모바일 24권)**이 꽂히고, 오래된 책은 책장 화면의 목록에서만 보인다 (#36). 책장 화면의 탭은 다 읽은 책 / 포기한 책 / 나중에 읽을 책이다.

| 항목 | 내용 |
|---|---|
| 이번 달 달력 | 한국 시간 기준 현재 월을 표시 |
| 독서한 날 표시 | 스탠드를 끄며 시간을 저장했거나 책을 완독한 날에 색과 점을 표시. 오늘은 테두리 |
| 연속 독서일 | 오늘 또는 어제부터 연속으로 기록이 있는 날짜를 센다. 같은 날 여러 번 읽어도 하루. 기록이 없으면 0일(헤더에는 숨김) |
| 달 이동 | 달력 위의 ‹ ›로 지난 달을 볼 수 있다(이번 달보다 뒤로는 못 감). 지난 달은 읽기 전용이고 독서한 날, 그 달의 목표와 결과(`완독 2/3권 · 목표 미달성`)만 보인다. 연속 독서일은 이번 달에만 보인다. 기록이 있는 가장 이른 달까지 갈 수 있다 |
| 월 완독 목표 | 기본 1권, 1~99권으로 변경. **달마다 따로 보관한다(#39)**: 이번 달에만 고칠 수 있고 지난 달 목표는 바뀌지 않는다. 새 달이 되면 직전에 정한 목표를 이어받는다("지난 달 목표를 이어받았어요"). 처음 기록 이전의 달은 "목표 기록 없음" |
| 목표를 바꿨어요 표시 | 달 중간에 목표를 바꾸면 그 달의 목표 카드에 `🔁 목표를 바꿨어요 · 3→4권 (11.17)`이 남는다(지난 달을 볼 때도 보인다). 같은 날 여러 번 바꾸면 한 번으로 합치고(여러 날이면 `, 2번`), 처음 값으로 돌아오면 표시가 사라진다 |
| 목표 달성 현황 | `완독 2/3권`처럼 그 달 완독 수와 목표를 함께 표시. 지난 달은 `목표 달성/미달성`을 덧붙임. 포기한 책은 제외 |
| 방 안 모습 | 벽걸이 달력에 이번 달, 독서한 날, 완독 현황이 그려짐 |
| 알림 | 없음 |

### 캐릭터
- 바닥을 누르면 걸어간다. 가구를 누르면 **패널은 바로 열리고** 캐릭터는 뒤에서 걸어간다.
- 소파를 누르면 정면을 보고 앉는다. 읽는 책이 있으면 책을 펼쳐 든다.
- 앉은 상태에서 스탠드를 누르면 일어나지 않는다. 다른 곳을 누르면 일어난다.

### 발견성과 접근성

| 항목 | 방식 |
|---|---|
| 클릭 가능 표시 | 마우스 기기: 호버 외곽선 + 상태 툴팁. 터치 기기: 입장 시 가구가 차례로 1초 반짝임 |
| 신규 알림 표시 | 가구는 움직이지 않는다. 새 알림이 있는 가구에 **노란 별**(✦)이 깜빡인다. 거울: 새 아이템, 창문: 가져오기 대기 중인 종료된 공유방 (창문을 열면 사라짐), 소파: 올려 둔 책이 없을 때 (책을 올리면 사라짐). 문에는 알림 표시를 두지 않는다 |
| 배지 | 쓰지 않는다. 신규 알림은 노란 별로만 표시 |
| 키보드 | 숨긴 버튼 목록으로 Tab 순서: 소파 → 스탠드 → 책장 → 달력 → 거울 → 창문 → 문 |
| 히트박스 | 보이는 가구보다 크게 |
| 모션 줄이기 | `prefers-reduced-motion`이면 별 점멸, 창 열림, 토스트 연출을 끔. 걷기 이동은 기능이라 그대로 |

## 2. 소파 흐름

| 단계 | 내용 |
|---|---|
| 비어 있음 | [책 찾기]에 **책 제목이나 저자**를 넣으면 표지·제목·저자·쪽수가 있는 책 목록이 나오고, 고르면 제목·저자·전체 쪽수·표지가 한 번에 채워진다. **ISBN은 사용자가 입력하지 않는다.** 고른 책의 ISBN은 내부 식별자로 저장돼 공유방 책 매칭·책 정보 연결에 쓴다(숫자를 붙여 넣으면 찾아 주지만 화면에서 안내하지 않는다). 찾지 못하거나 인터넷이 없으면 제목·저자(·전체 쪽수)를 직접 입력 → 소파에 두기. 한국 책은 서버의 국립중앙도서관 검색(결정 #56, 백엔드 구현됨·화면 연결은 남음)으로 찾는다 |
| 읽는 중 | 표지와 책 정보, **현재 쪽 / 전체 쪽 → 퍼센트 자동 계산**, 메모/인용구 + 쪽(선택) 추가·삭제, [포기] [완독] |
| 완독 | 별점(선택), 한줄평(선택) → 책장에 꽂기 |
| 포기 | 확인 후 "포기한 책"으로 이동, 메모는 보존 |

- 퍼센트는 `현재 쪽 ÷ 전체 쪽`으로 계산하고(100% 상한), 전체 쪽수를 모르면 퍼센트를 보여주지 않고 안내만 한다. 전체 쪽수는 책을 찾을 때 채워지거나 직접 적는다.
- 메모·인용구에 쪽을 적으면 그 쪽이 지금까지 읽은 쪽보다 클 때 현재 쪽이 자동으로 올라가고 퍼센트도 바뀐다. 작은 쪽을 적어도 현재 쪽은 내려가지 않는다.
- 스탠드를 끌 때도 슬라이더 대신 현재 쪽을 적는다.

소파에는 한 권만 올릴 수 있다 (`READING`은 사용자당 1개).

## 3. 스탠드 타이머

### 원칙
- 켜는 건 한 번에, 끄는 건 어디서든, 깜빡하면 나중에 물어본다.
- **서버 시각 기준**: 시작할 때 `started_at`을 저장하고, 화면 숫자는 표시용이다. 창을 닫거나 화면이 꺼져도 기록은 계속된다.
- 실제로 읽었는지는 감지하지 않는다. 사용자를 믿고 상한과 확인 단계로 이상한 기록만 거른다.
- 일시정지는 없다. 끄고 다시 켜면 세션이 하나 더 생긴다.

| 상황 | 동작 |
|---|---|
| 켜기 | 소파에 책이 있어야 함 → [스탠드 켜고 읽기 시작] → 캐릭터가 소파에 앉아 책을 듦 |
| 읽는 중 | 스탠드 위, 패널, 헤더에 경과 시간 |
| 끄기 | [💡 스탠드 끄기] → 현재 쪽(퍼센트 자동 표시) + 한 줄 메모(선택) → [끄고 저장] |
| 1분 미만 | 기록하지 않음 |
| 60분마다 | "아직 읽고 있어요?" [계속] [스탠드 끄기]. 웹은 화면 배너 + 브라우저 알림(페이지를 열어 둔 동안), 앱은 로컬 알림. 스탠드를 처음 켤 때 알림 권한을 요청. [계속]을 누르면 다시 60분 뒤 |
| 3시간 초과 알림 | "확인이 필요해요"를 한 번 보낸다 (`NEEDS_CONFIRM`) |
| 공유방 알림 | 창문의 예정 방에서 [알림 받기]를 켜 두면 개방 시각에 "이야기방이 열렸어요" 알림. 누르면 창문이 열린다 |
| 3시간 초과 | 자동 종료하지 않고 `NEEDS_CONFIRM` → 다음 접속 때 [마지막으로 '계속'을 누른 시각까지] [직접 입력] [기록 안 함] |
| 밖에서 읽음 | 직접 기록: 오늘/어제 + 분 |
| 완독·포기 | 켜져 있으면 자동으로 끄고 기록 |
| 다른 기기에서 켬 | `RUNNING`은 사용자당 1개 → 기존 세션으로 이어감 |

### 플랫폼별

| 환경 | 화면 밖 표시 | 비고 |
|---|---|---|
| 데스크톱 웹 | **바탕화면에 띄우기** (Document PiP): 소파에 앉은 캐릭터 + 시간. **스탠드를 누르면 꺼지며 기록** 후 창이 닫힘 | 크롬·엣지 116+, 파이어폭스 151+. 사파리와 모바일은 미지원 → 버튼 숨김. 위쪽 주소 바는 웹에서 제거 불가 |
| 모바일 웹 | 없음. 다시 들어오면 `visibilitychange`/`pageshow`에서 재동기화 | 웹 푸시는 iOS에서 홈 화면 추가 시에만 |
| 앱 | iOS 라이브 액티비티, Android 고정 알림, 예약 로컬 알림 | 앱 전환 때 |
| 데스크톱 앱 | 투명·테두리 없는 창 캐릭터 | 상용화 이후 |

## 4. 거울 (캐릭터 커스터마이징)

| 항목 | 내용 |
|---|---|
| 레이아웃 | 2단 모달: 왼쪽 큰 미리보기 + 셔플 버튼(교차 화살표 아이콘만), 오른쪽 선택창. 좁은 화면에서는 위아래로 쌓음 |
| 캐릭터 | 3D 유령 (다리 없음, 시트 몸). 바닥에 그림자를 드리우지 않는다. 서 있을 때는 가슴 앞에 **양손 모두 같은 동그란 주먹**(좌우 대칭, #42), 앉아 책을 읽을 때는 두 손이 둥글어져 책을 잡음 |
| 항목 순서 | 색상 → 표정 → 얼굴 장식 → 머리 장식 → 손에 든 소품 |
| 간격 | 항목 사이 16px, 제목과 선택지 사이 8px, 선택지끼리 8px |
| 선택지 | 색상 8가지, 표정 5가지(기본·웃음·놀람·졸림·윙크), 얼굴 장식 4가지(없음·동그란 안경·선글라스·반창고), 머리 장식 5가지(없음·비니·리본·왕관·새싹), 손에 든 소품 5가지(없음·책·찻잔·랜턴·풍선) |
| 셔플 | 모든 항목을 무작위로. 해금된 것만 |
| 프리셋 | 없음 (셔플로 대체) |
| 저장 | 저장 전에는 미리보기만. 취소하면 되돌림 |
| 해금 | 첫 책 기록 → 동그란 안경, 10권 → 비니. 장르별 보상은 추후 |
| 노출 | 방, 헤더 아바타, 바탕화면 창, 마을, 공유방 (거울에는 비치지 않음) |

## 5. 마을과 공유방 (프로토타입 있음)

### 마을 화면

| 항목 | 내용 |
|---|---|
| 들어가기 | 내 방의 문을 누르면 유령이 문으로 걸어가 마을로 나간다. 마을의 내 방(집)을 누르면 걸어가서 방으로 돌아온다 |
| 지도 | 걸어 다니는 큰 마을(약 36×27칸). 내 방, 이웃집 8채, 내 집 남쪽(화면 왼쪽 아래)의 돌바닥 **광장**(대화 구역, 약 13×10칸), 동쪽(화면 오른쪽) 흙바닥 **모닥불 구역**(공유방, 약 12×22칸), 연못, 나무, 가로등. 방과 달리 한눈에 보이지 않는다. 걸을 수 있는 범위 바깥도 풀밭과 숲이 이어져 지도 끝이 화면에 보이지 않는다 |
| 미니맵 | 마을 화면 오른쪽 위에 정사각형(약 112px) 상자로 마을 전체를 위에서 내려다본 모양(오른쪽이 x, 아래가 z)으로 작게 보여준다. 마을에는 설명문이 없어서 상자가 화면 오른쪽 위 모서리(위·오른쪽 12px)에 놓인다. 위아래 남는 자리는 바깥 숲 색이다. 광장·모닥불 구역·연못·집(내 집은 붉은색)·모닥불(열림 주황, 예정 흰색, 종료 회색, 가져온 방 파랑, 빈 자리 흰 테두리)·이웃(초록 점)·나(노란 점)가 표시된다. 보기만 하고 눌러도 반응하지 않는다. 방에서는 숨긴다 |
| 접속 인원 | 마을 화면 하단 오른쪽에 `접속 (06/100)`(접속/정원)을 작고 연한 글자로 표시한다. 눈에 띄는 배지나 상단 표시는 쓰지 않고, 다른 곳에는 인원을 표시하지 않는다(광장 채팅창이 떠 있는 동안은 하단 글자를 숨기고 채팅창 제목에 같은 숫자를 보여준다, #40). 체험판은 보이는 이웃 5명 + 나 = 6명 예시값. 서버 단계: 마을 동시 접속 정원 100명(가득 차면 입장 안내. 초대 링크·모닥불 참여자도 예외 없이 기다린다. 내 방은 항상 사용 가능), 화면에는 가까운 20명까지만 그린다 (#35) |
| 갈림길 | 내 집에서 나오면 앞길이 갈라진다. 남쪽(왼쪽)으로 내려가면 광장, 동쪽(오른쪽)으로 꺾으면 광장을 거치지 않고 모닥불 구역 입구로 간다. 갈림길 푯말과 미니맵의 길이 이를 알려 준다 (#45) |
| 구역 구분 | 두 구역은 바닥과 경계로 나뉜다. 광장은 돌바닥에 낮은 연석, 모닥불 구역은 흙바닥에 서쪽 나무 울타리와 입구 문(위쪽 길이 닿는 북서쪽에 있다. 꾸밈일 뿐 막지 않는다, 유령은 울타리를 통과한다). 모닥불은 모닥불 구역에만 놓이고, 광장에는 놓이지 않는다 (#34) |
| 광장 대화 | **모달이 아니라 마을 화면 위의 반투명 채팅창**이다(#40). 광장(돌바닥) 안에 서 있으면 자동으로 뜨고 밖으로 나가면 사라진다. PC는 화면 왼쪽에 **폭 300px, 높이는 배경(마을 화면) 높이에 맞춰 세로로 길게**(위·아래·왼쪽 12px 여백. 접으면 제목 줄만 왼쪽 아래에 남는다), 폰은 화면 하단 전체 폭에 **높이 230px 고정**으로 놓이고(글이 많아도 크기는 변하지 않고 안에서 스크롤) 폰 키보드가 올라오면 키보드 위로 올라온다. 스크롤바는 화살표·바탕 없이 얇고 연한 둥근 막대다. 제목(`💬 광장 이야기 · 접속 (06/100)`)을 누르면 접어 둘 수 있다. 책이 달라도 광장에 온 이웃과 한 줄(40자)로 말하고, 말하면 머리 위에 말풍선이 5초쯤 뜬다. 광장 가운데 분수대를 누르면 그 자리로 걸어간다(창을 따로 열지 않는다). 글은 하루 뒤 사라진다. 공유방 이야기는 모닥불 안에서만 한다 (#34). 채팅창이 떠 있는 동안에는 하단의 `접속 (06/100)` 글자를 숨긴다(제목에 있음) |
| 카메라 | 유령을 부드럽게 따라간다. 폰 기준으로 화면에 가로 약 14칸이 보인다(가로로 넓은 창에서는 더 넓게 보인다). 방은 지금처럼 고정이고, 따라가는 카메라는 마을에서만 쓴다 (#30) |
| 이동 | 바닥을 누르면 그 자리로 걸어간다. 지도를 **누르고 끌면** 지도(화면)가 움직이고 캐릭터는 그대로 있다. 걸어가라고 하면 다시 캐릭터를 따라간다(#46). 방보다 빠르다. 집이 있는 뒤쪽 줄과 지도 가장자리는 걸을 수 없다 |
| 마을 게시판 | 광장 위쪽. 누르면 공유방을 열린 방 / 곧 열릴 방 / 지난 방으로 묶어 보여주고, 각각 [들어가기] [알림 받기] [내 서재로 가져오기]를 둔다 |
| 공유방 모닥불 | 모닥불 구역에 열린 방·예정 방마다 모닥불 하나(최대 8개). 열린 방은 활활 타고, 예정 방은 불이 안 붙은 상태다. 종료된 방은 마을에 모닥불이 없고 게시판 "지난 방"에 7일 남는다(#53). 누르면 그 방의 창이 열린다 |
| 이름표 | 집, 게시판, 모닥불 위에 이름이 뜬다. 모닥불은 `● 방 이름 · D-2`(직접 지은 이름 우선, 이름을 안 지으면 책 제목)처럼 상태를 함께 보여준다 |
| 이웃집 | 창문에 불이 켜지고 꺼진다 (다른 사람이 읽는 중이라는 분위기). 내 방은 스탠드를 켜면 창에 불이 켜진다 |
| 풍경 | 계절은 월, 날씨는 날짜로 바뀐다. 창문의 풍경과 같은 값을 쓴다. 하늘 색은 날씨를 따른다 |
| 공유방 대화 | 모닥불을 누르거나 [들어가기]를 누르면 모닥불 창이 대화 화면으로 열린다 (#38, 기능 정의서 3.11). 방마다 처음 한 번 보관 동의 고지("종료 후 7일 뒤 사라져요, 가져가면 다른 사람 이름은 참여자 A로 바뀌어요")를 보고 들어간다. 모닥불 장면의 대화창에는 대화만 있고, 참여자·방 정보는 대화창 옆의 동그란 아이콘 버튼(참여자·방 정보)으로 여는 별도 모달이다(마을 모달은 탭 [대화] [참여자] [방 정보], #44). 책 제목은 한 화면에 한 번만 쓴다. 글은 최대 300자이고 3초에 3건까지, 직전 글과 같은 글은 30초 안에 다시 보낼 수 없다(#61). 같은 책 방은 내 현재 쪽이 글에 자동으로 붙고(칩으로 고치기·빼기), 대화는 모두 보이고 내가 완독·포기하지 않은 같은 책 방은 입장 전과 대화 위에서 스포를 알리며 [나중에 읽을 책에 담기]를 준다(#43). 참여자 진행 퍼센트는 숨긴다. 내 글은 삭제할 수 있고, 방을 나가면 내 글은 "나간 참여자"로 남는다. 종료 후에는 읽기 전용이며 상단 띠에 `종료됐어요 · 가져오기 마감 D-n`과 [내 서재로 가져오기]가 있고, 불씨가 남은 일수만큼 작아진다. 안 읽은 글이 있으면 마을 모닥불 위와 창문에 노란 별(✦)이 뜬다 |
| 공유방 장면 | 열린 방에 입장하고 보관 동의를 마치면 별도의 밤 숲 모닥불 장면으로 전환한다. 모닥불이 중앙에서 타고, 내 캐릭터와 참여자 캐릭터가 둘러앉아 책 이야기를 나눈다. PC는 오른쪽에 대화 패널, 폰은 화면 아래에 대화 패널을 둔다. [마을로] 또는 닫기로 돌아간다. 참여자 캐릭터는 체험판 예시 모습이며 실제 동시 접속과 연동하는 것은 서버 단계다 |
| 알림 표시 | 없음 |

### 공유방 개설 · 모닥불 피우기

공유방은 **사용자가 직접 개설**한다 (결정 #32). 마을의 빈 모닥불 자리("+ 모닥불 피우기")나 마을 게시판의 [모닥불 피우기]를 누르면 개설 창이 열린다.

| 항목 | 내용 |
|---|---|
| 방 종류 | **같은 책**: 모두가 같은 책을 읽는다. 끝나면 내 책장의 그 책에 대화가 담긴다. **각자 읽기**: 각자 다른 책을 읽고 이야기한다. 내가 고른 책에 대화가 담긴다 (결정 #33) |
| 책 | 같은 책은 필수(소파에서 읽는 책, 책장의 책, 직접 입력 중 선택). 각자 읽기는 "내가 읽을 책"을 고르며 아직 안 정해도 된다 |
| 표시 | 각자 읽기 방은 대화창 부제에 책 제목 대신 "각자 읽기"를 쓰고, 모닥불 이름표는 `@나무 『모순』`처럼 읽는 책을 붙인다. 닉네임은 한글·영문·숫자만 1~5자이고 공백·이모티콘·특수문자는 쓸 수 없다 (결정 #52·#67) |
| 방 이름 | 비우면 자동: 같은 책은 `『책』 같이 읽기`, 각자 읽기는 `○○의 모닥불` |
| 시작 | 지금 바로 / 예약(날짜·시각). 예약은 지금보다 뒤여야 한다 |
| 진행 시간 | 1~7시간(기본 3시간). 시작부터 센다. 시간이 다 되면 저절로 종료되고 장면에 있던 사람은 광장으로 돌아온다. 장면에 머문 시간은 오늘 읽은 시간에 더해진다 (#53) |
| 공개 범위 | **초대 링크로만.** "마을에 공개"는 베타에 두지 않는다(#41, 코드의 `PUBLIC_ROOMS` 스위치로 다시 켤 수 있다) |
| 최대 인원 | 2~10명, 기본 8명. 정원이 차면 더 들어올 수 없다. 모닥불 장면에는 의자 6개(내 자리 포함)와 뒤쪽 빈터에 서 있는 자리 4개가 있어 10명이 모두 보인다 (#54) |
| 스포 안내 | 같은 책 방에서 내가 완독·포기하지 않은 책이면 입장 전 경고와 대화 위 띠로 알리고 [나중에 읽을 책에 담기]를 준다. 대화는 모두 보인다 (#43) |
| 개설 제한 | 동시에 열 수 있는 모닥불은 2개(종료된 방은 세지 않는다). 하루(한국 시간)에 3번까지 개설할 수 있고 취소해도 돌려주지 않는다. 3번을 다 쓰면 다음날 만든다 (#53) |
| 초대 링크 | 개설하면 8자리 초대 코드와 링크(`…#join=코드`)가 생긴다. 링크 칸 옆의 복사 아이콘 버튼, 공유 아이콘 버튼(지원하는 기기만). 링크를 열면 마을로 들어가 그 모닥불 창이 열린다. 마을 게시판의 "초대 링크로 들어가기"에 링크나 코드를 붙여 넣어도 된다 |
| 방 닫기 | 개설자가 예약 방은 [모닥불 취소], 열린 방은 [일찍 끝내기]. 끝내면 그날부터 게시판에 7일 보관 |
| 보낸 글 | 삭제도 수정도 할 수 없다 (#53) |
| 자동 전환 | 시작 시각이 되면 열리고(알림 받기를 켠 사람에게 알림), 기간이 끝나면 종료되어 7일 보관 뒤 사라진다. 개설자는 자동으로 알림을 받는다 |
| 프로토타입 한계 | 서버가 없어 이 브라우저에서 만든 방만 링크로 열린다. 친구가 들어오는 것은 테스트 도구 [친구 1명 들어오기]로 흉내 낸다. 대화가 없으니 가져올 내용도 없다 |

### 공유방 규칙 (기획)

| 항목 | 내용 |
|---|---|
| 마을 게시판 | 공유방 개방 시기, 내가 참여한 공유방 기록을 내 서재로 가져가는 버튼 |

### 이웃집에 추천 책 꽂아 두기 (2026-11-18)

- 마을 이웃집을 눌러 방문하고 책장을 누르면 추천 책 선택 창이 열린다. 벽·바닥·다른 가구 없이 책장과 내 캐릭터만 가운데 크게 보여주는 고정 구도를 쓰고, 방 테두리는 유지하며 배경은 분홍 체크무늬 벽지다(결정 #51). 책장을 누르면 추천하고 [← 마을로]로 돌아간다.
- 내 소파에서 읽는 중인 책 또는 완독한 책만 [책 꽂기]로 추천한다. 포기·나중에 읽을 책은 제외하고 저장 시에도 현재 자격을 다시 검사한다. 내 책과 기록은 변경하지 않는다.
- 한 집에는 미확인 추천 한 권만 둔다. 꽂으면 선택 창이 닫히고 책장 아래 칸에 책이 약 0.9초 동안 들어온다. 동작 줄이기 설정이면 즉시 놓인다.
- 새로고침·재방문 후에도 남는다. 집 주인이 책장에서 [확인했어요]를 누르면 추천 칸이 비어 다시 추천할 수 있다. 확인만으로 완독·나중에 읽을 책에 추가하지 않는다.
- 내 집에 도착한 추천은 책장 아래 칸과 노란 별(✦)로 표시한다.
- 이웃은 시연용이다. 이웃집 책장의 [테스트 도구 → 집 주인 시점으로 보기]에서 확인을 체험한다. 실제 전달 API는 서버에 구현됐고(`neighbor` 패키지, 결정 #62: 추천 카드에 보낸 사람의 닉네임을 밝히고 집 주인 본인만 확인한다), 화면 연결은 다음 단계다.

## 6. 계정과 첫 접속

| 항목 | 내용 |
|---|---|
| 로그인 | 아이디·비밀번호 없음. 베타는 **초대 링크 + 구글**. 카카오·Apple은 나중에 추가 (결정 #55) |
| 계정 구조 | 내부 ID(밖으로 나가지 않음) / 공개 번호(무작위 UUID, 다른 사람에게 보이는 고정 번호) / 로그인 수단(provider + provider_user_id) / 닉네임(바꿀 수 있음). **핸들은 없다** (결정 #69) |
| 식별 기준 | 이메일이 아니라 provider가 주는 고유 ID |
| 앱 전환 | 웹과 앱이 **같은 구글 계정 고유 ID(`sub`)**로 사용자를 찾으면 계정이 이어진다(앱용 OAuth 클라이언트는 따로 만들어도 된다). 카카오·Apple을 나중에 더하면 같은 사람의 로그인 수단을 `auth_identity`에 연결한다 |
| 첫 접속 | 초대 링크 → 구글 → 닉네임 → 캐릭터 → 내 방 → 소파 안내 |
| 첫 방문 안내 | 1단계: 소파만 밝게 "소파를 눌러 지금 읽는 책을 올려보세요" [건너뛰기]. 2단계: 스탠드 강조 "스탠드를 켜면 읽는 시간이 기록돼요". 프로토타입에서는 평소에 뜨지 않고 [데모 초기화]를 눌렀을 때만 시작됨 |
